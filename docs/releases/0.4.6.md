## Changes in 0.4.6

- Added time-range and operation filters to Records > Update history, with a reset action and search across event descriptions.
- Added selected-event details with UpdateID, revision, client/source context, HRESULT explanations, suggested next steps, and a copy action.
- Added copyable failure summaries grouped by HRESULT and operation, including event counts and the latest occurrence. Summaries use the current filters and identify the limits of the loaded history.
- Handle absent timestamps and zero HRESULTs explicitly, preserve selection while filtering when possible, and arrange history controls for narrower windows.

Validation: 79 core tests and 39 Windows infrastructure tests passed; WinUI code checks and the native x64 Release build passed without warnings or errors. The updated app was launched. Interactive verification of the new history controls has not been performed.
