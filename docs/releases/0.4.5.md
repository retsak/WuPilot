## Changes in 0.4.5

- Consolidated the sidebar into six workspaces. Compare scans, Watchlist, and Registered sources are tabs within Scan and review; Update history and Session activity live under Records.
- Redesigned the Command center around everyday switches, clear effective/requested/pending values, and a sticky Review and apply bar. Flip a switch back to cancel its pending change; expand Advanced policies and change history for detailed editing and audit records.
- Fixed narrow-window clipping in switch cards, scan setup, and result filters. Keyboard search opens advanced policies and scrolls the search field into view.
- Preserved the original policy value when a pending change is edited after refresh, so applying still detects conflicting device changes. Editing is locked during readback and review/apply.
- Automatically load registered sources and update history on first opening. Startup update checks report availability without interrupting work with a modal prompt.
- Added a standalone PowerShell update-log collector/report generator and a read-only Windows log-health audit, with documentation. Collection warnings are collapsed below report timings.

Validation: 74 core tests and 39 Windows infrastructure tests passed; WinUI code checks and native x64 publishing passed. Native UI checks covered staging, reversing switches, canceling review, grouped navigation, compact layouts, and keyboard filtering. No device policies or updates were applied during UI testing. Published app manifest resources retain the administrator requirement.
