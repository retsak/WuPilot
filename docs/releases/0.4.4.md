# WuPilot 0.4.4

Feature-update reports now identify the update from WindowsUpdateClient events and confirm completion using a successful installation event for the same update GUID. A constituent package finishing or Windows booting cannot substitute for success of a known update identity. Existing cumulative-package correlation remains available when no update-identity event is present.

Setup-log analysis now streams full collected files by default instead of stopping at 500,000 lines. Regenerating a report refreshes supporting analysis from available raw log snapshots, recovering evidence omitted by older analysis limits. Explicit caller-supplied parsing limits remain supported.

The updated parser was checked against before/after bundles from a live Windows 11, version 26H2 update on October 2, 2026: 26 seconds for download preparation, 37 seconds for installation to restart-required, and approximately 65 seconds from shutdown to identity-matched update success. Removing the matching success event leaves completion unconfirmed. These boundaries measure logged activity and reported update success, not exact click-to-desktop time. Captured device logs are not included in the release.

Regression coverage includes markers after 500,000 lines, regeneration of old supporting evidence, feature-update identity matching, unrelated updates, provider filtering, and failure-event rejection. Release automation runs core and Windows infrastructure tests, the WinUI compilation gate, and builds self-contained x64 and ARM64 installers, portable desktop packages, and standalone collectors with SHA-256 sidecars.
